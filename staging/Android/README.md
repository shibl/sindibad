# Android

The future Android app. Not started yet.

Today the game runs on Android phones in the browser from [`Web/`](../Web/),
works offline, and can be added to the home screen. A native app would
follow the brief ([`docs/original-project-brief.md`](../docs/original-project-brief.md)):
light enough for 2 GB phones, fully offline, and sharing updates over the
local network or Bluetooth.
