> **[نتيجة:]**
> **التصاوغ الموضعي: يحدثُ عندما تكون للجزيئات الصيغة المُجمَلة ذاتها، ولكنّها تختلف بموضع الزمرة الوظيفيّة في الجزيء.**

#### ثالثاً: التصاوغ الوظيفيّ:

> **[نشاط (6):]**
>
> ألاحظُ المُتصاوِغَين الآتيَين:
>
> 🖼️ **[البوتانال]** و **[البوتان–2–ون]**
> *وصف:* صيغتان منشورتان: إلى اليمين **البوتانال**: سلسلة من أربع ذرات كربون أفقية تبدأ بذرة H على اليسار وتنتهي بذرة H على اليمين؛ ذرات الكربون الثلاث الأولى (من اليسار) تحمل كل منها H في الأعلى وH في الأسفل، وذرة الكربون الرابعة (اليمنى) مرتبطة برابطة مضاعفة بذرة O في الأعلى وبذرة H على اليمين (زمرة فورميل). إلى اليسار **البوتان–2–ون**: سلسلة من أربع ذرات كربون أفقية بين ذرتي H طرفيتين؛ ذرتا الكربون الأولى والثانية (من اليسار) تحمل كل منهما H في الأعلى وH في الأسفل، وذرة الكربون الثالثة مرتبطة برابطة مضاعفة بذرة O في الأعلى (زمرة كربونيل)، وذرة الكربون الرابعة تحمل H في الأعلى وH في الأسفل.
>
> ```
>         H   H   O   H                    H   H   H   O
>         |   |   ‖   |                    |   |   |   ‖
>     H — C — C — C — C — H            H — C — C — C — C — H
>         |   |       |                    |   |   |
>         H   H       H                    H   H   H
>          (البوتان–2–ون)                       (البوتانال)
> ```

> **[إضاءة]**
>
> الصيغة العامة للكيتونات $\mathrm{R-\overset{\overset{\displaystyle O}{\|}}{C}-R'}$ تحتوي على زمرة الكربونيل $\mathrm{-\overset{\overset{\displaystyle O}{\|}}{C}-}$
>
> الصيغة العامة للألدهيدات $\mathrm{R-\overset{\overset{\displaystyle O}{\|}}{C}-H}$ وتحتوي على زمرة الفورميل $\mathrm{-\overset{\overset{\displaystyle O}{\|}}{C}-H}$

> - أحدّدُ الزمرة الوظيفية.
> - أحدّدُ الصيغة المُجملَة لهذَين المُتصاوِغين.

> **[نتيجة:]**
> **تصاوغ الوظيفة: يحدث عندما تكون للجزيئات الصّيغة المُجمَلة ذاتها، ويختلفُ بها ترتيب الذرّات ضمن الجزيء ممّا يؤدّي إلى اختلاف الزمرة.**
