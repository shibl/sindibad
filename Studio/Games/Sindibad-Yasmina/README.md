# Sindibad & Yasmina

Learning experiences are organised by school class under [Classes](Classes/README.md), covering Grades 1–12. The project directory is `Studio/Games/Sindibad-Yasmina/`, as requested by the owner.

- [Grade 6](Classes/Grade6/README.md): the existing Sindibad & Yasmina web game, native Kotlin Android app, future iOS app, shared artwork, and documentation.
- [Grade 10](Classes/Grade10/README.md): Chemistry Lab, canonical chemistry/physics textbook transcriptions, and the archived rejected board prototype.
- All other class directories are reserved; their existence does not imply playable lessons.

`Web/`, `Android/`, and `iOS/` are platform workspace indexes for class-owned implementations. `Infra/` documents deployment. Each existing application's source has one home under its class.
