# Design A reference assets

Design A reconstructs the No Jiggery homepage shown in the supplied 2026-10-29
screen recording, with Sindibad copy and project screenshots. These assets were
retrieved from the reference site on 2026-10-29 and are retained locally for visual
fidelity and to avoid runtime third-party requests.

- `remote.svg`, `hug.svg`, `mobile-cup.svg`, `union-pink.svg`, `quote-pink.svg`,
  `99-quote.svg`: https://nojiggery.co/wp-content/themes/nojiggery/assets/images/icons/
- `craft-1.avif` through `craft-4.avif`: reference service-card illustrations from
  https://nojiggery.co/wp-content/uploads/2026/02/ (chess collage, modular character,
  research collage, interface funnel). These are reference artwork, not Sindibad
  game screenshots. Their original rights remain with their respective owners.
- `bricolage-grotesque.woff2` and `figtree.woff2`: reference site font files;
  SIL Open Font License notices are included alongside them. Upstream families:
  https://github.com/ateliertriay/bricolage and https://github.com/erikdkennedy/figtree.

Sindibad's game screenshots remain in `../img/`. No reference logo, customer
endorsement, client logo or contact identity is reproduced. Carousel quotations
are explicitly studio principles; future project entries are labeled concepts.
