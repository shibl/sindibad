## Artwork prompt

Use case: stylized-concept. Create high quality 16:9 wide promotional key art for the educational adventure game Sindibad & Yasmina. Reference image is the actual game island map: preserve its welcoming maritime world, turquoise sea, sandy green islands, lighthouse, small stone harbour castle, wooden sailing dhow, discovery voyage motif. Reimagine this world as premium hand-painted storybook game illustration with fine painterly textures and beautiful sunlit water, aerial three-quarter perspective, atmospheric depth, elegant composition with prominent dhow approaching the harbour and islands receding into the distance. Warm cream sails, teal sea and soft peach sunlight. Suitable for cropping to a tall project card as well as a landscape website hero: keep central ship and harbour visible in central third. No text, no interface, no logos, no invented characters. Artwork inspired by the game, not a purported gameplay screenshot.
