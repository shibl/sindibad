# Google Sans Flex

Full variable font from Google Fonts: https://github.com/google/fonts/tree/main/ofl/googlesansflex

Axes: weight 1–1000, width 25–151, optical size 1–144, roundness 0–100, slant -10–0. The OFL license is included. The splash uses the reference letter tracking keyframes with this font. Arabic remains Noto Sans Arabic.
